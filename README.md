# Inglês para Viagens

Landing page em React + Vite, preparada para importar no Lovable via GitHub.

## Rodar localmente
```bash
npm install
npm run dev
```

## Antes de publicar
1. Inserir o link real de checkout da oferta em `checkoutUrl`, no início de `src/App.jsx`.
2. Validar a entrega do PDF e os materiais bônus.
3. Revisar os valores de referência dos bônus e as condições comerciais.
4. Inserir política de privacidade, termos e dados de contato do responsável pela oferta.
5. Acrescentar depoimentos e indicadores somente quando houver dados reais e autorização de uso.

## Estrutura
A página mantém a lógica comercial da referência: abertura da oferta, identificação do problema, apresentação da solução, conteúdo organizado, demonstração do formato, bônus, perfil do público, oferta, perguntas frequentes e rodapé.

## Identidade visual
Azul marinho e azul médio como base, branco e azul muito claro nos fundos, amarelo suave nos destaques. Elementos gráficos remetem a passaporte, embarque e viagem.
